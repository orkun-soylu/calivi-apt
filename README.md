# calivi-apt

The APT repository for [Calivi](https://github.com/orkun-soylu/calivi), served at
**https://apt.calivi.ai** by GitHub Pages.

This repository is written only by Calivi's release workflow, and only after the package passed
its tests on every supported distribution (Debian 13, Ubuntu 24.04 LTS, Ubuntu 26.04 LTS).
Do not commit here by hand.
